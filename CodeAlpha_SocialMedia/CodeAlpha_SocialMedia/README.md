# CodeAlpha_SocialMedia

Mini social media app built for CodeAlpha Full Stack Internship (Task 2).

**Stack:** HTML/CSS/JavaScript frontend, Node.js + Express backend, SQLite database.

**Features:** user registration/login (JWT + bcrypt), user profiles with bio, posts, comments, likes, follow/unfollow, "Following" feed.

## Run
```
npm install
npm start
```
Open http://localhost:3000. The database (`social.db`) is created automatically.
