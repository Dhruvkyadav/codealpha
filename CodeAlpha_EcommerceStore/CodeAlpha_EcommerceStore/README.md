# CodeAlpha_EcommerceStore

Simple e-commerce store built for CodeAlpha Full Stack Internship (Task 1).

**Stack:** HTML/CSS/JavaScript frontend, Node.js + Express backend, SQLite database.

**Features:** product listing, product details, shopping cart, user registration/login (JWT + bcrypt), order processing, order history.

## Run
```
npm install
npm start
```
Open http://localhost:3000. The database (`shop.db`) and sample products are created automatically.
